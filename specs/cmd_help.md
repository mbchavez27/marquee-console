# Command: `help`

**Pre-conditions:** None.
**Trigger:** User types "help".
**Action:**

1. Print a cleanly formatted list of all available commands: `help`, `start_marquee`, `stop_marquee`, `set_text`, `set_speed`, `clear_screen`, `exit`.
2. Include a short description for each command beside it.
   **Post-conditions:** The console prompts the user for the next command.
